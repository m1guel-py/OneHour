# OneHour
<img width="1899" height="921" alt="image" src="https://github.com/user-attachments/assets/b120893c-9b48-4625-a261-c8ba946e2e1e" />

O **OneHour** é um aplicativo de foco inspirado na técnica Pomodoro, desenvolvido para auxiliar nos períodos de estudo e descanso.
A proposta é dividir o tempo em ciclos de:
- 30 minutos de estudo
- 15 minutos de descanso
O objetivo do projeto é proporcionar uma forma simples de organizar os períodos de foco durante os estudos.
