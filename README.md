# OneHour

<img width="1359" height="765" alt="image" src="https://github.com/user-attachments/assets/a3f8da96-9752-4662-a9b0-b853d237c75f" />

O **OneHour** é um aplicativo de produtividade desenvolvido para auxiliar nos estudos por meio de ciclos de foco e descanso inspirados na técnica Pomodoro.

Por padrão, o aplicativo utiliza ciclos de:
- **30 minutos de foco**
- **15 minutos de descanso**

A duração dos ciclos pode ser personalizada nas configurações.

O objetivo do projeto é oferecer uma maneira simples e prática de organizar os períodos de estudo, ajudando o usuário a manter uma rotina de foco e pausas.

## Tecnologias

- JavaScript
- HTML
- CSS
